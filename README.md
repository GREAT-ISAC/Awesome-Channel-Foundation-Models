# Awesome Channel Foundation Models

A community-maintained catalog of **Channel Foundation Model (CFM)** research and reusable resources for AI-native wireless systems.

## Browse the catalog

| Browse | What you will find |
|---|---|
| [CFM papers](papers/README.md) | Research taxonomy with available implementation and evaluation links |
| [Datasets](datasets/README.md) | Measured and simulated data with associated evaluation links |
| [Simulation tools](simulation-tools/README.md) | Channel, ray-tracing, and system-level simulation infrastructure |
